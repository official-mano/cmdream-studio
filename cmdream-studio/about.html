WHAT IT IS

A simple idea,
carefully made.

No timeline to learn and no account to create. Describe an animation, then use the studio to shape, inspect, and export it.

01 / COMPOSE

Start without setup.

The built-in rule-based composer works offline for its supported subjects. Optional local or cloud models can help with other ideas.

02 / RENDER

Keep the drawing safe.

Models can return a constrained JSON scene plan. The fixed renderer validates that data and draws each frame; model-provided code is never executed.

03 / TAKE IT WITH YOU

Your scenes stay yours.

Scene history is saved locally on the device. Inspect the JSON, export a standalone HTML animation, or download a scene pack.

THE WORKSPACEOne focused canvas

Prompt, preview, playback, local history, and scene code in one place.

THE COMPOSERYour choice

Offline rules, local Ollama in desktop, or supported providers with your own credentials.

THE PRINCIPLEData, not scripts

Scenes are constrained plans. The renderer—not model code—creates the motion.

that moves.
