01 / QUICK START

Start with an idea.

Open the workspace, describe one subject and how it should move, then choose Compose scene. The offline composer is ready immediately for flowers, hearts, rings, fireworks, stars, smoke, waves, and houses—no account, model, or API key needed.

To install the desktop app, visit the Download Center, choose a published package for your operating system, then follow the installer or AppImage instructions on that page. Unpublished packages are shown as unavailable.

02 / WORKSPACE

Compose, review, export.

  1. Describe a subject, motion, and mood. For example: “a silver ring turning slowly in blue starlight.”
  2. Choose a detail level and compose. For subjects outside the offline composer’s built-in set, connect a local or cloud composer in Settings.
  3. Use play, pause, restart, seek, and speed controls to review the loop. Enable Fine detail for a denser terminal grid.
  4. Open Scene code to inspect the validated JSON plan. Export it as JSON or as a standalone HTML animation.

Your recent scenes and non-secret composer preferences are saved in this browser or desktop app on this device. They are not synced to an account.

03 / COMPOSERS

Choose where composition happens.

Offline composer: built in and rule-based. It works without a network or model weights, supports the subjects listed above, and does not promise to understand every possible prompt.

Ollama: install Ollama on the same computer, download a model yourself, then choose Ollama in desktop Settings and test the connection. Model weights are not bundled. A Render-hosted website cannot connect to Ollama running on a visitor’s computer.

Cloud providers: configure your provider, model or deployment ID, endpoint where required, and API key in Settings. Supported adapters include OpenAI, Anthropic, Google Gemini, Azure OpenAI, and OpenAI-compatible endpoints. Browser-based provider requests may depend on the provider’s CORS settings; the desktop app sends them through its local Electron process.

04 / PRIVACY

Your prompt, your choice.

The offline composer sends no prompts anywhere. Ollama requests go to the local Ollama service on your computer. When you select a cloud provider, your prompt and API key are sent to that provider to compose or test a connection; CMDream does not receive them.

Provider names, model IDs, endpoints, and selected composer may be remembered locally. API keys are held in memory only and are cleared when the page or app closes. Scene history stays in local browser or desktop storage.

05 / HOW IT WORKS

Plans are data. Frames are drawn.

  • The web interface and renderer use HTML, CSS, and JavaScript bundled with Vite.
  • The desktop app packages the same workspace with Electron and a restricted localhost bridge for Ollama.
  • Built-in rules or an optional model produce a constrained JSON scene plan.
  • The validator rejects unsupported values. A fixed renderer draws the scene and its loop; model-returned scripts and markup are never executed.
  • CMDream does not train or bundle a foundation model. You install Ollama and any model weights separately if you choose local AI.
06 / TROUBLESHOOTING

Common questions.

Ollama cannot connect.

Confirm Ollama is running on this computer and that you have downloaded a model (for example, ollama pull llama3.2). In desktop Settings, use the local endpoint http://127.0.0.1:11434 and test the connection. The hosted website cannot access your computer’s local Ollama service.

My prompt is not recognized offline.

The offline composer only covers its built-in subject set. Connect an AI composer for other subjects, or try a supported subject such as a flower, heart, ring, fireworks, stars, smoke, waves, or house.

Why is a download unavailable?

A platform download is enabled only after a package has been built and published to the project’s file host. The owner must upload the package and deploy its catalog entry before the button becomes active.

Windows warns that the application is unsigned.

The Windows packages are not code-signed. SmartScreen may show a warning, especially for new downloads. Signing requires a code-signing certificate and does not guarantee immediate removal of reputation warnings.

07 / PROJECT STATUS

What is included.

Implemented

Offline scene composition, validated scene plans, looping terminal rendering, local history, provider adapters, desktop packaging, and direct downloads from the configured product catalog.

Set up by the owner

Desktop packages must be built and uploaded before they can be downloaded. Cloud AI requires the user’s own provider credentials.

Not included

CMDream does not supply or train an LLM, store user API keys, or sync scenes to an account.
