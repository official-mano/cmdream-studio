01 / ABOUT

Terminal art, animated.

CMDream Studio is a small animation studio for people who want to describe a scene instead of learning a timeline. It creates looping, colored character-grid animations and lets you adjust playback, inspect the scene plan, and export the result.

A built-in offline composer handles its supported subjects without an account or model. Optional AI providers can suggest a constrained plan for custom requests.

02 / AVAILABLE FEATURES

Included in this version.

  • Looping scenes for flowers, hearts, rings, fireworks, stars, smoke, waves, and houses, plus validated custom shape plans from configured AI models.
  • Five scene detail levels, fine-grid preview, playback controls, local scene history, optional synced scene history, JSON inspection, and standalone HTML export.
  • Built-in offline composer; optional Ollama desktop integration and OpenAI, Anthropic, Gemini, Azure OpenAI, and OpenAI-compatible provider adapters.
  • Electron desktop packages configured for Windows x64 and ARM64, and Linux x86_64 AppImage. Unsigned Windows builds may show SmartScreen warnings.
03 / INSTALLATION

Install and launch.

Desktop: open the Download Center, choose your platform, download the latest release, then run the installer or AppImage. The Windows installer offers a setup flow, shortcuts, and an uninstaller.

Web: open the hosted site and choose Open the studio. The offline composer works in the browser; Ollama integration requires the desktop app.

For local development, install Node.js 22 or later, run npm install in the application folder, then npm run dev. Run npm test and npm run build to validate the project.

04 / WORKSPACE

Create, refine, export.

  1. Describe one scene, its motion, and a mood (for example: “a silver ring turning slowly in blue starlight”).
  2. Choose a detail level and select Compose scene. If a request needs a custom subject, choose an AI composer in Settings.
  3. Use play, pause, restart, seek, and speed controls to review the loop. Turn on Fine detail for a denser preview.
  4. Open Scene code to inspect the validated JSON, then download the scene JSON or standalone HTML.

Scene history is stored locally. Sign in optionally to merge and sync the most recent 100 scenes through an owner-scoped account table. Signing out leaves the local history intact.

05 / AI & PRIVACY

Choose where composition happens.

Offline composer: built in, no model weights, API key, or network request. It supports the subjects listed above; it does not promise to understand every possible prompt.

Ollama: install Ollama and download a model yourself. In desktop Settings, choose Ollama, select the local model, and test the connection. Model weights are not bundled. A Render-hosted website cannot connect to Ollama running on a visitor’s computer.

Cloud providers: enter your own endpoint, model or deployment ID, and API key in Settings. Provider requests are sent directly to the selected provider. CMDream does not receive them. The selected provider, model IDs, and endpoints can be remembered locally; API keys remain in memory and are cleared when the app or page closes.

Account service: account credentials and authentication tokens are managed by the configured Supabase project. Scene prompts and validated scene data sync only after sign-in. Provider API keys are not included in synced data.

06 / TECHNOLOGY & SAFETY

Small, inspectable building blocks.

  • Website and renderer: HTML, CSS, and JavaScript bundled with Vite.
  • Desktop: Electron packages the same interface as a standalone application, with native File, Edit, View, and Window menus and a restricted localhost bridge for Ollama.
  • Scene composition: built-in deterministic rules, or optional provider responses constrained to a JSON scene contract.
  • Rendering: a fixed JavaScript renderer draws validated shapes and animation phases. Model-returned scripts and markup are never executed.
  • Hardware acceleration: no GPU-specific acceleration feature is advertised or required by CMDream.

CMDream Studio does not train or bundle a foundation model. You install Ollama and any model weights separately if you choose local AI.

07 / TROUBLESHOOTING

Common questions.

Windows warns that the app is unsigned.

Windows builds are not signed with a code-signing certificate. SmartScreen may show a warning, particularly for a new download. Signing requires a trusted certificate and does not guarantee immediate removal of reputation warnings.

Ollama cannot connect.

Confirm Ollama is running on this computer, that at least one model has been downloaded (for example, ollama pull llama3.2), and that the endpoint in desktop Settings is http://127.0.0.1:11434. Ollama is not available from the hosted website.

A custom prompt is not recognized by the offline composer.

The offline composer only covers its built-in subject set. Choose a configured AI composer for a custom subject, or try a supported prompt.

There are no download buttons that work.

The download catalog currently has no published file URLs. The project owner must build and upload release installers to Cloudflare R2, then deploy the updated product catalog. Until that is done, the download center disables those buttons rather than sending you to a broken link.

I cannot create an account.

Account registration requires the owner to configure a Supabase project, apply the database migration, and build/deploy the app with its public URL and publishable key. Account creation is unavailable until those steps are complete. Offline scenes do not require an account.
