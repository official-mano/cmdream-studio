SYSTEM REQUIREMENTS

What you need.

  • Windows 10 or later. Select x64 for most Intel/AMD PCs or ARM64 for Windows-on-ARM PCs.
  • 64-bit x86 Linux desktop environment. AppImage may require FUSE 2; Debian packages target Debian/Ubuntu-style systems.
  • macOS on Intel or Apple silicon. The first launch may show an unsigned-app security warning.
  • Internet access to download the app. Offline composition works after installation.
  • Ollama and model weights are separate downloads; they are not bundled.
INSTALL & UPDATE

Get started.

  1. Choose the package matching your platform and processor.
  2. Windows Setup creates Start Menu and desktop shortcuts. Linux packages add an application launcher; macOS disk images contain the app for Applications.
  3. Uninstalling removes the program, not your locally saved scenes. Install a newer version to update.

Windows and macOS builds are unsigned and may show operating-system security warnings.
