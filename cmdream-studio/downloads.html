SYSTEM REQUIREMENTS

What you need.

  • Windows 10 or later. Select x64 for most Intel/AMD PCs or ARM64 for Windows-on-ARM PCs.
  • 64-bit x86 Linux desktop environment for the AppImage; some systems may require FUSE 2 compatibility.
  • Internet access to download the app. Offline composition works after installation.
  • No CMDream-specific RAM minimum is published; optional Ollama model resource needs depend on the model you install.
  • Ollama and model weights are separate downloads; they are not bundled.
INSTALL & UPDATE

Get started.

  1. Choose the package matching your platform and processor.
  2. Run the Windows installer for Start Menu and desktop shortcuts, or open the portable executable without installing.
  3. To update, install the newest version from this download page. Local scene history remains in the app profile.

Windows builds are unsigned. Windows may show a SmartScreen warning; signing requires a trusted code-signing certificate.
